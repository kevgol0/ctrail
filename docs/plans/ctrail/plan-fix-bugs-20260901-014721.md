## Bug Fixes

### 1. `-v` overwrites `-f` — CtrailEntryPoint.java:279-281
**Problem:** Both `-f` and `-v` set the same `enabledFileFiltering` boolean. `-v` should control exclude filtering independently.  
**Fix:** Add `enabledExcludeFiltering` property to CtrailProps. Wire `-v` to it. Update FileSearchFilter/FileTailTracker to respect it.

### 2. Stdin with no match/filter drops all input — StdinReaderThread.java:74-84
**Problem:** `run()` only calls `runWithSearchFiler()` or `runWithMatch()`. No fallback → silent data loss.  
**Fix:** Add `else` branch that reads all lines and outputs them unfiltered.

### 3. `Hashtable.contains()` checks values not keys — CtrailProps.java:337
**Problem:** `_fileSearchFilters.contains(fname)` checks values.  
**Fix:** Change to `containsKey(fname)`.

### 4. Missing format arg in log — CtrailProps.java:441
**Fix:** Add `color_` as the argument.

### 5. Missing format arg in error log — CtrailProps.java:381
**Fix:** Add second argument or fix the format string.

### 6. Thread-unsafe LineFormatter fields
**Fix:** Convert instance fields `_tmp*` to local variables in `format()`.

### 7. `refreshProps()` on every line — LineFormatter.java:77
**Fix:** Remove per-line refresh. Props are immutable at runtime. Keep constructor init only.

### 8. Redundant `new String()` — CtrailProps.java:526
**Fix:** Remove wrapper, use `attr.getValue()` directly.

### 9. Double `]` in debug output — CtrailProps.java:268/285
**Fix:** Remove the duplicate `dbg.append("]")` at line 285 for the case-sensitive branch (it's already appended at 268).

### 10. Drain loop uses `pollLast` (LIFO) — OutputWriterThread.java:111
**Fix:** Change to `pollFirst`.

### 11. `runWithMatch` case-sensitive in stdin — StdinReaderThread.java:149
**Fix:** Apply same case-sensitivity logic as FileReaderThread (check `useCaseSensitiveSarch`).

### 12. `shouldExcludeLineDueToSeachTerms` ignores `_defLineExclude` — FileTailTracker.java:126
**Fix:** Return `_defLineExclude` when `_fileSearchFilter` is null instead of hardcoded `false`.
